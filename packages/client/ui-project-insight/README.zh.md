# @deepseek-ai/dsh-client-ui-project-insight

[English](README.md) | 中文

开发模式的洞察标签：五个 `conversation.view` 注册，渲染会话项目的已提交 project-insight 文档。每个标签展示一个已扫描区段——模块依赖拓扑、组件依赖、技术栈、组件与 agent 相关技术——按环形顺序排在 trajectory 标签之后。提示词区段渲染在 agent 相关技术标签的提示词二级标签里，因此不单设标签。文档及其区段由 host 服务 [`@deepseek-ai/dsh-project-insight`](../../insight/project-insight/README.zh.md) 生成。

标签通过会话级 `modes` 过滤器限定在 `develop` agent preset：过滤器仅在会话已解析 preset 属于其 `modes` 时显示标签，因此将会话切换进开发模式会默认显示五个标签，切换出去则隐藏它们。未声明 `modes` 的条目（chat、trajectory）始终显示。

每个标签拥有一个会话级 `ProjectInsightController`，通过特权 `projectInsight.read` RPC（读取项目文件即侦察）按会话当前 `cwd` 读取会话文档。全新文档立即渲染；`none` 与 `stale` 意味着 host 可能仍在扫描，因此控制器每隔两秒重新读取，直到线上报告 `fresh`。代数计数器使最新的 `load`（或 `dispose`）取代所有更早的在途读取与已排程轮询，因此会话切换绝不会闪现上一会话的文档。文档缺失或正在重扫时，标签渲染居中的框架态——忙碌状态在状态文案旁带旋转指示，未扫描与不可读为纯文案——与应用其它加载呈现一致。

两个依赖区段渲染满铺的 React Flow 依赖图——平移、缩放与滚轮来自库本身，互引循环成员以红色高亮——完整的模块或组件列表以半透明面板悬浮在画布左缘，选中文件的内容抽屉悬浮在画布右缘。每个节点卡片以边框、文字与背景色调承载其文件类型（TypeScript 蓝、JavaScript 琥珀、组件绿、样式品牌色，其余中性），选中节点带最强的高亮——品牌色边框、填充与 3px 高亮环——在整个画布上可辨识。列表、抽屉与画布双向同步：悬停列表行即给节点加高亮环，选中则以聚焦缩放把画布居中到该节点、高亮其相连边并打开该文件内容的抽屉（documents 内容池携带该文件时渲染内嵌内容，否则渲染其行 JSON）；悬停或点按画布节点即高亮并滚动对应列表行并打开同一抽屉；点按背景或关闭抽屉即清除选中。未进入有界节点集的行仍列出但置灰标注「未在图中」；面板可收起，让画布独占全部宽度。模块图丢弃外部叶子与被省略目标、经路径别名打标签，并按度封顶节点、按数量封顶边；工具栏说明文字标明各封顶省略了什么；边集为空的区段回退为浏览器树而非画布。

技术栈、组件与 agent 相关技术区段渲染为左树右详情的浏览器：左窗格是派生的组/叶子树（技术栈：运行时、清单、按清单类别的依赖、按语言的源文件；组件：按父目录逐组；agent 相关技术清单：按文件角色逐组并附加工具根；技能、MCP、提示词集合：按文档目录逐组），右窗格经 shiki 高亮的 `CodeBlock` 渲染选中组的 JSON——选中任意文件行时改为渲染该文件的内嵌内容：markdown 文档经 `MarkdownText` 渲染（围栏代码块带 shiki 高亮），其他文件经按扩展名给出语法提示的 `CodeBlock` 渲染（ts/tsx、js/jsx、vue、svelte、yaml、json、toml、ini 等按扩展名，未知扩展名纯文本）。文件内容经所有标签共享的 documents 内容池解析；agent 相关技术清单把自身集合叠放在内容池之上，MCP 配置的脱敏内嵌绝不被其原始源码遮蔽；被文档上限排除的行回退为其行元数据 JSON，工具叶子解析其引用文件的内容。agent 相关技术区段在其清单与内嵌内容集合之上渲染二级标签；该区段与浏览器都加入会话输入框覆盖层，因此标签栏与窗格保持固定，标签内容在其下滚动，且每个滚动区预留悬浮输入框座位的高度。

## 模型体验

无——标签渲染已提交文档，绝不触及模型；`projectInsight.read` RPC 读取项目文件但不产生任何模型输入。

#### KV Cache 影响

无——标签不添加任何提示词内容，读取结果也不是任何模型请求的一部分。

## 已知局限与延后工作

- **依赖图有封顶**——模块图仅保留度最高的节点与有界边数，因此大型项目的可视部分不完整；悬浮完整列表兜底完整性，工具栏说明文字标明各封顶省略了什么。
- **组详情是 JSON 而非叙述**——浏览器右窗格把选中组的已提交行渲染为高亮 JSON；只有文件与文档行获得内容渲染。
- **提示词 markdown 来自 agent 相关技术内嵌**——纯元数据的 `prompts` 区段不含内容，因此 agent 相关技术的提示词二级标签渲染该区段的内嵌提示词集合，受其前几行与字节上限约束。
- **新鲜度滞后于文件变化**——`stale` 文档每两秒重新读取，直到 host 报告 `fresh`，因此标签更新前必须完成扫描并经过轮询间隔。
- **无项目则无标签**——没有 `cwd` 的会话没有可扫描内容，标签渲染为空。
- **仅开发模式**——除非会话已解析 preset 为 `develop`，否则标签保持隐藏；其他 preset 不显示本包的洞察标签。
- **嵌入文档有界**——agent 相关技术的内容集合与共享 documents 内容池按集合封顶行数、按文档与总计封顶字节（schema 常量），因此文件多而大的项目只显示前几行；MCP `env` 值以脱敏形式到达。
