# @deepseek-ai/dsh-client-ui-project-insight

[English](README.md) | 中文

开发模式的洞察标签：六个 `conversation.view` 注册，渲染会话项目的已提交 project-insight 文档。每个标签展示六个已扫描区段之一——模块依赖拓扑、组件依赖、技术栈、组件、提示词与 agent 相关技术——按环形顺序排在 trajectory 标签之后。文档及其六个区段由 host 服务 [`@deepseek-ai/dsh-project-insight`](../../insight/project-insight/README.zh.md) 生成。

标签通过会话级 `modes` 过滤器限定在 `develop` agent preset：过滤器仅在会话已解析 preset 属于其 `modes` 时显示标签，因此将会话切换进开发模式会默认显示六个标签，切换出去则隐藏它们。未声明 `modes` 的条目（chat、trajectory）始终显示。

每个标签拥有一个会话级 `ProjectInsightController`，通过特权 `projectInsight.read` RPC（读取项目文件即侦察）按会话当前 `cwd` 读取会话文档。全新文档立即渲染；`none` 与 `stale` 意味着 host 可能仍在扫描，因此控制器每隔两秒重新读取，直到线上报告 `fresh`。代数计数器使最新的 `load`（或 `dispose`）取代所有更早的在途读取与已排程轮询，因此会话切换绝不会闪现上一会话的文档。

两个依赖区段渲染满铺的 React Flow 依赖图——平移、缩放与滚轮来自库本身，互引循环成员以红色高亮——完整的模块或组件列表以半透明面板悬浮在画布之上。列表与画布双向同步：悬停列表行即给节点加高亮环、选中则高亮它，悬停或点按画布节点即高亮并滚动对应列表行。未进入有界节点集的行仍列出但置灰标注「未在图中」；面板可收起，让画布独占全部宽度。模块图丢弃外部叶子与被省略目标、经路径别名打标签，并按度封顶节点、按数量封顶边；工具栏说明文字标明各封顶省略了什么。技术栈与组件区段渲染为卡片、徽章与两列表格。提示词标签与 agent 相关技术区段的技能、MCP、提示词二级标签渲染文档标签栏加单个可滚动 markdown 面板，经 `MarkdownText` 展示。提示词标签的 markdown 取自 agent 相关技术区段的内嵌提示词集合——扫描器对两者都用同一 `isPromptFile` 判定，因此两个标签是同一逻辑集合的不同呈现——并显示总数对比已展示数的计数行；内嵌为空的项目回退到纯元数据文件表。

## 模型体验

无——标签渲染已提交文档，绝不触及模型；`projectInsight.read` RPC 读取项目文件但不产生任何模型输入。

#### KV Cache 影响

无——标签不添加任何提示词内容，读取结果也不是任何模型请求的一部分。

## 已知局限与延后工作

- **依赖图有封顶**——模块图仅保留度最高的节点与有界边数，因此大型项目的可视部分不完整；悬浮完整列表兜底完整性，工具栏说明文字标明各封顶省略了什么。
- **列表选中只加亮环不平移**——视图适配整个图并在容器变化时重新适配，但悬停或选中列表行不会将视口移到其节点，因此视图之外的节点保持在外，直到用户平移；画布点按会把该节点的列表行滚动进悬浮列表的视野。
- **提示词 markdown 来自 agent 相关技术内嵌**——纯元数据的 `prompts` 区段不含内容，因此提示词标签渲染 agent 相关技术区段的内嵌提示词集合，受其前几行与字节上限约束；仅当内嵌为空时，标签回退到纯元数据文件表。
- **新鲜度滞后于文件变化**——`stale` 文档每两秒重新读取，直到 host 报告 `fresh`，因此标签更新前必须完成扫描并经过轮询间隔。
- **无项目则无标签**——没有 `cwd` 的会话没有可扫描内容，标签渲染为空。
- **仅开发模式**——除非会话已解析 preset 为 `develop`，否则标签保持隐藏；其他 preset 不显示本包的洞察标签。
- **嵌入文档有界**——agent 相关技术的 markdown 集合按集合封顶行数、按文档与总计封顶字节（schema 常量），因此技能或提示词文件多而大的项目只显示前几行；MCP `env` 值以脱敏形式到达。
