# @deepseek-ai/dsh-client-ui-flow-editor

[English](README.md) | 中文

一个可视化流程画布，作为环形顺序 15 的单个 `conversation.view` 条目（"流程"）——排在 trajectory 标签（10）之后、开发模式洞察标签（20+）之前。画布面向 host 流程引擎 [`@deepseek-ai/dsh-flow`](../../workflow/flow/README.zh.md) 编排、持久化、运行并观察分支多 agent 流程：添加 agent、条件与循环节点，连接它们，并驱动一次运行。

该条目是通用用途——不限定任何 agent preset。组合中挂载了流程引擎的会话可以编排并运行分支工作流；没有引擎时，host 对每个 `flow.*` 调用都回答 `flow-unavailable`，标签改为渲染只读提示而不是画布。随 Web 组合包 `dsh-web-app` 发布的组合默认挂载引擎，因此画布开箱即用；只读提示是省略该引擎的自定义组合的回退。

每个会话拥有一个 `FlowEditorController`，按会话当前 `cwd`（来自 sessions feed）键控，因此工作区切换会为新目录重新加载画布。控制器：

- 列出并打开会话已保存的流程（`flow.list` / `flow.get`），目录为空时默认最近保存的流程或未保存的 starter；
- 保存、重命名与删除流程（`flow.save` / `flow.delete`），首次保存时从图名生成 id；
- 在本地编辑图（节点、连线、agent 提示词、provider/model 路由与按类型的模型路由）并以 JSON 输入框启动运行（`flow.run`）；解析失败会在任何线上流量之前拒绝运行；
- 每 800 ms 轮询 `flow.getRun` 直到运行落定，在画布上绘制每个节点的状态，并列出运行历史（`flow.listRuns`）；`flow.stop` 取消实时运行。

Agent 选项只携带非空的 provider/model 值，每个按类型路由同样丢弃被清空的字段或类型：清空字段会丢弃该键而不是发送空字符串，与引擎的 `!== undefined` 选项语义一致。

画布是可平移缩放的网格点阵。左侧调色板提供可拖拽的 Agent、条件与循环卡片（工具栏按钮仍作为无障碍回退）；拖动背景平移视图，滚轮以指针为锚缩放（限制在 0.2×–2×），Delete/Backspace 删除选中的节点或连线。背景拖拽必须越过 3 px 的移动阈值才算平移；静止按下仍是取消选中的点击。节点位置位于视图变换之下的图空间，因此拖放的节点落在光标下的图坐标点。

## 模型体验

间接地，通过 host 流程引擎：画布编排并运行的图会编译成 `dsh-flow` 组装的子 agent 提示词，而画布本身不贡献任何提示词内容。

#### KV Cache 影响

无——画布不添加任何提示词内容，也没有任何运行结果是模型请求的一部分。

## 已知局限与延后工作

- **连线拒绝文案未本地化**——被拒绝的连线提示（自环、重复、两分支已满）是直接设置到状态的英文字面字符串；只有运行输入拒绝是本地化的。
- **空运行输入被当作非法 JSON 拒绝**——输入框默认 `{}`；清空成空串会使 `JSON.parse` 失败并拒绝运行，因此即使引擎接受缺失输入，也没有"无输入运行"路径。
- **无自动布局**——新节点级联到最右节点右侧；没有自动排列，手工摆放的布局保持原样。
- **触屏拖拽可用，触屏平移延后**——画布设置 `touch-action: none`，因此节点拖拽在触屏上正常触发（`pointermove` 而非 `pointercancel`）；指针式平移与滚轮缩放已随本版交付，但触屏平移与捏合缩放仍延后。
- **轮询状态而非流式**——实时节点状态通过 800 ms 的运行快照轮询更新；没有推送通道。
- **无引擎时只读**——省略流程引擎的自定义组合（随 Web 组合包 `dsh-web-app` 发布的组合会挂载它）显示提示而没有画布；失败是线上的 `flow-unavailable`，不是客户端门控。
- **流程按会话隔离而非共享**——已保存流程目录按会话 `cwd` 限定；同一目录中的两个会话在保存前互不可见彼此的草稿。
