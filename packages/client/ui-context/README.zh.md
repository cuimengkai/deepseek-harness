# @deepseek-ai/dsh-client-ui-context

[English](README.md) | 中文

会话上下文标签页：一个 `conversation.view` 注册，通过特权 `contextComposition.read` RPC 渲染会话当前模型可见的上下文组成。宿主侧折叠位于 [`@deepseek-ai/dsh-context-composition`](../../session/context-composition/README.zh.md)。

该标签页是活跃会话视图。它为每个会话持有一个 `ContextCompositionController`，挂载时读取会话的组成，并在会话最后事件 seq 变化（新消息、工具调用或压缩——运行时快照已携带的修订标记）时重新读取。代数计数器让最新的 `load`（或 `dispose`）取代所有更早的在途读取，因此会话切换不会闪现上一个会话的组成。读取在途时标签页渲染一个带共享 spinner 的居中框架，与应用其他加载表现一致；尚无请求的会话渲染空框架。

主体是容量条 + 左树/右详情浏览器。容量条把启发式占用——系统提示词、工具目录、对话表面——按最新记录的路由容量分段展示，窗口已知时展示剩余尾段，未知时展示明确的未知标记；百分比钳制，因此超估不会破坏布局。左树按信封行（系统提示词、工具目录）、每个计价表面消息一行、每个已完成压缩一行分组；右窗格渲染选中行：系统提示词按 markdown、工具目录按名称/tokens 表、表面消息的预览、或压缩的摘要文本及其写入路由与影子价格。页脚标注快照描述的日志修订。

该标签页还能发起手动压缩。普通点击选中一行；在表面行上 shift 点击会从最近普通点击的锚点扩展范围（锚点消失时改为以被点击行为锚点），高亮覆盖的所有行，并显示带闭区间摘要（行数与 token 总和）的操作条。触发按钮通过 commands Remote 发送 `/compact <startSeq>:<endSeq>`：获接纳的执行会清除范围（压缩事件移动修订标记、组成重读、收缩后的表面与新历史行出现），被拒绝则保留范围并展示引擎的失败文案。失败文案保持英文（错误展示策略：不本地化）。

## 模型体验

间接，经由范围触发所路由的压缩引擎：标签页自身的读取渲染的是会话日志的投影，`/compact` 斜杠输入与直接结果绝不进入模型请求，获接纳的压缩会用后端检查点替换所选表面范围——这一模型可见的变化可从已记录的 `compaction/*` 与替换事件完整重建。

#### KV Cache 影响

标签页的读取不添加提示内容，不影响缓存。获接纳的范围压缩从第一个被遮蔽的历史 token 起使缓存复用失效，与其他压缩一致。

## 已知限制与后续工作

- **数字是启发式的，非提供商报告** — 标签页展示 token-meter 的固定密度估算（与 meter 及 `contextBreakdown` 投影同一口径），但不是提供商的精确分词；压力投影的提供商样本才是精确数字，位于别处。
- **按表面修订刷新** — 重读在会话最后事件移动时触发，因此纯日志事件（请求头变化、路由容量广告）在下一次表面移动或标签页重挂载前不会刷新。
- **读取仅宿主面** — 组合中未挂载 `@deepseek-ai/dsh-context-composition` 的部署每次读取都以内部拒绝失败，标签页渲染错误框架；fixture 连接提供离线平行实现，因此 fixture 驱动的应用仍可渲染。
- **范围由引擎校验** — 标签页发送原始 seq 端点并原样渲染引擎的拒绝；它不预校验工具调用配对或已遮蔽行成员关系，因为宿主侧的 surface 折叠拥有该事实。
