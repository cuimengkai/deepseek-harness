# Agent Note: Compose an agent preset on a pipeline canvas

Status: implemented

English | [中文](2026-08-23-agent-preset-canvas-composer.zh.md)

## Problem

The row-compose composer shipped as a searchable palette beside a flat chip column, but the module names had no annotation — the inventory's `category`/`description` were discarded at the surface — and the composition column read as an unordered list, not as the ordered chain `agent.cordis.yml` actually is. The request was a Dify-style visual canvas: the palette must say what each plugin does, the right column must support real orchestration, and composing an agent and letting Creator mode draft one should be one flow rather than two parallel buttons.

## Decision

The composer becomes a horizontal pipeline on a canvas that owns the whole settings content area — still pure client, with the row-structure/wire decision of the [row-compose note](2026-08-23-agent-preset-row-compose.md) unchanged: the canvas fills the section's full width and height under the settings top bar, and the palette and inspector float over it as layers rather than side columns — the pipeline is the workspace, not a column in one. The composition's head label (`组合`) sits above the canvas as a fixed head, outside the layered region, so a floating panel never covers it. The shared 960px cap is gone from the settings sections as a whole, not just the composer: Models, Plugins, and Agent presets all fill the width like General, and the Plugins inventory renders its rows as a responsive `auto-fill` card grid. The palette is the annotated inventory — `PaletteModule { moduleName, displayName, category?, description? }` surfaced from `pluginInventory.list()`'s existing entries, grouped by spine category (uncategorized modules share the `其他` bucket, which is never a real category), searchable across module name, display name, category, and description, with a typed glyph, display name, category badge, and clamped description per card; it is expanded by default and collapses to a tab on the canvas edge. The canvas renders a Dify-style chain from Start through one node per plugin row to End: chain order IS the row order written to the host, and there is no branching or edge-dragging because `agent.cordis.yml` is an ordered row list with no runtime execution-flow semantics. The inspector floats over the right edge only while a node is selected, showing the selected node's category, display name, mono module name, row id, description, and remove/move-up/move-down actions; clicking the canvas background deselects.

Creator mode stops being a standalone card and becomes the composer's footer handoff (`让 Agent 帮我搭建/完善`), which is save-then-handoff: it saves the composition and starts a session staged on the self-referential `cordis` preset, closing the settings panel as the old card did. An untouched preset (`composeBlocker === 'unchanged'`) skips the save and hands off directly, because `confirmCompose` otherwise no-ops. The handoff is present only when the conversation fiber provides `startCreatorDraft` AND the roster carries `cordis`, so the capability is gated where it is used.

The insertion-line fix surfaced in e2e. The drop-slot indicator was a flex child toggling inside a keyed fragment; showing it swapped the fragment's head element for the line span, which detached the dragged node and cancelled the native drag in Chromium — reordering was impossible. The line is now an absolutely-positioned overlay positioned from `slotBoundaries()` against `data-canvas-track`, so the chain never reflows under a drag.

A shipped preset's `查看` action opens the read-only design page instead of the previous raw-YAML dialog: the same canvas renders the shipped chain with nothing editable — no palette, no id or name fields, no save, and the nodes neither drag nor offer a remove control.

`apps/web/tests/agent-preset-composer.e2e.ts` drives the real canvas keylessly: drop-in, append (the last node's right half), and reorder. The canvas fills the stage, so the drop target sits clear of the floating palette — the palette's right edge (~608px) and the drop slot's center (~950px) are disjoint in the 1680px viewport, and a palette drag releases on the canvas, never on the panel; the reorder-scroll helper is now a no-op for short chains. `agent-preset-authoring.e2e.ts` pins the read-only view (the shipped chain renders on the canvas with no edit affordances) and covers the handoff: drag one plugin, fill the id, hand off, then assert the settings panel closes, `/api/session.list` reports `agentPreset: "cordis"`, and `my-agent/agent.cordis.yml` landed on disk before the session started.

## Alternatives considered

**Dify-style branchable graph.** Dify's nodes compose execution graphs with edges; an agent composition is an ordered row list mounted wholesale into one standing scope, so a graph would present affordances (branching, edge-dragging, loop nodes) the format cannot express. The canvas renders the chain order honestly instead of inventing flow.

**Keep the two-button split (composer card + Creator card).** The creator card's only job was staging `cordis` and starting a session; the composer's footer handoff does the same after saving the draft, so a separate card would duplicate entry points for the same flow. `cordis` remains selectable from the new-session chip either way.

**Inline insertion line as a flex child.** It shifted the chain, which both moved the drop slot under the pointer and — by detaching the dragged element mid-drag — cancelled the native drag in Chromium. Absolute positioning in the track's coordinate space gives a live preview with no reflow.

## Consequences

The composer surface no longer contradicts the format underneath: the canvas's chain IS the row order, and `config`/`disabled` ride along unedited in the wire rows. The section head is outside the layered region, so a floating panel can no longer cover the `组合` label; the read-only view renders the shipped chain on the canvas instead of a raw-YAML dialog, and the Models, Plugins, and Agent-preset sections all fill the width like General, with the Plugins inventory as a responsive card grid. Creator mode is reachable from the composer footer, so the empty-composition hint points at it and the roster's own create surface stays `新建 Agent`. The insertion line is out of the flex flow, so the drop-slot preview can neither reflow nor cancel a drag; the geometry the e2e must hit is documented in the test (the palette's right edge and the drop slot's center are disjoint, so a palette drag always releases on the canvas). Deferred: the handoff starts a blank session (no chat prefill), and the composer offers no per-plugin `config`/`disabled` editor — both recorded in the package README's Known Limitations.
